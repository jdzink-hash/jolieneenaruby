# The Way We Spend It

A magazine-style page for friends to share restaurant, café and activity picks, post upcoming plans, and keep a scrapbook of memories.

Live page: https://claude.ai/artifact/B5ipJKwWrzyEiQbJo2V4xc

- `index.html` is the whole page: styles, markup and script in one file.
- `stickers/` holds the cut-out icons, disco balls and stars the page uses.

Posts, hearts, "I'm in" and photos are stored by the Claude artifact the page is published as. Opened anywhere else (for example straight from this repo), the page shows its layout but can't load or save posts.
